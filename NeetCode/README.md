# NeetCode Open on LeetCode

[![Greasy Fork installs](https://img.shields.io/badge/dynamic/json?label=users&query=$.total_installs&url=https%3A%2F%2Fgreasyfork.org%2Fen%2Fscripts%2F606875.json&color=2ea44f)](https://greasyfork.org/en/scripts/606875-neetcode-open-on-leetcode)
[![Install from Greasy Fork](https://img.shields.io/badge/install-Greasy%20Fork-blue)](https://update.greasyfork.org/scripts/606875/NeetCode%20Open%20on%20LeetCode.user.js)

Adds **Open on LeetCode** next to the problem title on NeetCode. Click, middle-click, or use the keyboard to open the corresponding LeetCode problem in a new tab.

The link follows you as you switch problems within NeetCode. It appears when NeetCode identifies a LeetCode counterpart in the problem metadata.

If you installed the standalone **NeetCode → LeetCode Button** script, disable it when you install this version.
